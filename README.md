# حروف 🎯 — لعبة جماعية

لعبة تنافسية جماعية شبيهة بـ «بنت – ولد – حيوان – جماد – بلد»، يدخلها عدة لاعبين في نفس الغرفة ويتبارون في إكمال الخانات بحرف عشوائي واحد.

> «حروف 🎯» — مين أسرع واحد هيخلص؟

---

## ✨ المميزات

- 🎮 لعب جماعي حقيقي في الوقت الحقيقي (Supabase Realtime أو BroadcastChannel محلي).
- 🎯 حرف عشوائي واحد + 8 خانات افتراضية (يمكن تخصيصها).
- ⏱️ مؤقت تنازلي قابل للاختيار: 30 / 60 / 90 ثانية.
- ✅ زر COMPLETED واضح يطلق عدادًا من 10 ثوانٍ لباقي اللاعبين.
- 🔥 إشعار يظهر لجميع اللاعبين باسم أول من أنهى.
- 📊 جدول نتائج أنيق لكل جولة مع إبراز بطل الجولة.
- 🏆 شاشة تتويج نهائية بمنصة وأوسمة وconfetti.
- 🔁 إعادة اللعب بنفس اللاعبين.
- 🔇 كتم/تشغيل الأصوات.
- 🌙 تصميم عصري شبابي، RTL، Responsive بالكامل.
- 🛡️ بدون أي Secret Key في الواجهة (نستخدم anon key فقط مع RLS).

## 🚀 طريقة التشغيل السريع (بدون إعداد — للتجربة)

تعمل اللعبة **فورًا** في «الوضع المحلي» عبر `BroadcastChannel + localStorage`.
هذا يتيح لك تجربتها بين عدة تبويبات في نفس المتصفح دون أي إعداد:

1. افتح المجلد بأي خادم HTTP بسيط:
   ```bash
   cd hurouf
   python3 -m http.server 8080
   ```
   أو:
   ```bash
   npx serve hurouf
   ```
2. افتح `http://localhost:8080` في تبويب.
3. اضغط «إنشاء لعبة»، اكتب اسمك، أنشئ الغرفة.
4. انسخ الكود، افتح **تبويبًا آخر** على نفس الرابط، واضغط «دخول إلى لعبة».
5. كرّر مع تبويب ثالث إن أردت.
6. من تبويب الـ host، اضغط «ابدأ اللعبة» والعب.

> هذا الوضع مفيد للتجربة والتطوير. للعب الحقيقي عبر أجهزة مختلفة، اربط Supabase كما في الخطوات التالية.

## ☁️ ربط Supabase (للعب بين أجهزة مختلفة)

1. أنشئ مشروعًا على [supabase.com](https://supabase.com) (الباقة المجانية كافية).
2. افتح **SQL Editor** في لوحة Supabase والصق محتوى `supabase-schema.sql` ثم نفّذه.
3. من **Project Settings → API**، انسخ:
   - `Project URL`
   - `anon public` key (لا تستخدم service_role key إطلاقًا)
4. أنشئ ملف `config.js` بجانب `index.html` بالمحتوى التالي:
   ```js
   window.SUPABASE_CONFIG = {
     url: 'https://YOUR_PROJECT.supabase.co',
     anonKey: 'YOUR_ANON_KEY'
   };
   ```
5. أضف هذا السطر في `index.html` **قبل** `<script src="supabase.js"></script>`:
   ```html
   <script src="config.js"></script>
   ```
6. أعد تحميل الصفحة — ستلاحظ في console رسالة:
   `[HuroufSync] mode: supabase (Supabase Realtime)`

> 💡 يمكن بدلاً من ملف `config.js` فتح console المتصفح وتنفيذ:
> ```js
> localStorage.setItem('hurouf_sb_url', 'https://YOUR_PROJECT.supabase.co');
> localStorage.setItem('hurouf_sb_anon_key', 'YOUR_ANON_KEY');
> ```
> ثم إعادة التحميل.

> ⚠️ لا ترفع ملف `config.js` إلى مستودع عام. أضفه إلى `.gitignore`.

## 📖 طريقة اللعب

1. ينشئ أحد اللاعبين غرفة جديدة ويحصل على كود من 6 أحرف.
2. يشارك الكود مع أصدقائه (زر المشاركة ينسخ رابطًا جاهزًا).
3. يدخل اللاعبون بأسمائهم وينتظرون في غرفة الانتظار.
4. عند ضغط الـ host على «ابدأ اللعبة» يظهر للجميع حرف عشوائي.
5. يملأ كل لاعب خاناته بكلمات تبدأ بذلك الحرف.
6. أول لاعب يضغط **COMPLETED** يطلق عدادًا من 10 ثوانٍ لباقي اللاعبين.
7. تُعرض إجابات الجميع في جدول واحد، وتُحتسب النقاط تلقائيًا.
8. بعد العدد المحدد من الجولات، تظهر شاشة التتويج النهائية.

### نظام النقاط (قياسي)
- ✅ إجابة صحيحة وفريدة = **10 نقاط**
- ⚠️ إجابة صحيحة ومكررة مع لاعب آخر = **5 نقاط**
- ❌ إجابة خاطئة أو لا تبدأ بالحرف = **0**
- ⬜ الخانة الفارغة = **0**

يمكن للـ host اختيار نظام بديل: «صارم» (15/0/0) أو «متساهل» (10/7/3).

---

## 🎛️ الإعدادات القابلة للتخصيص

- عدد الجولات: 3 / 5 / 10 / مفتوح (∞)
- مدة الجولة: 30 / 60 / 90 ثانية
- الخانات: تفعيل/تعطيل أي من الخانات الافتراضية الثمانية قبل بدء اللعبة
- نظام النقاط: قياسي / صارم / متساهل
- الأصوات: كتم/تشغيل من زر السماعة في الرئيسية

---

## 🔒 الأمان

- لا يوجد أي **Secret Key** في الكود. نستخدم فقط `anon public key` الخاص بـ Supabase.
- مع Row Level Security المُفعّل في `supabase-schema.sql`.
- معرفة الكود السري (room code) هي حاجز الخصوصية الأساسي للغرفة.

---

## 🛠️ تعديل اللعبة

كل الملفات معلّقة بالعربية لشرح الأجزاء المهمة:

- `index.html` — بنية الشاشات السبع.
- `style.css` — تصميم عصري شبابي، RTL، Responsive، حركات وانتقالات.
- `app.js` — منطق اللعبة كامل (إدارة الشاشات، المؤقت، النقاط، الأصوات...).
- `supabase.js` — طبقة مزامنة موحّدة (Supabase أو Local Mode).

لإضافة خانة جديدة:
1. أضفها لمصفوفة `DEFAULT_CATEGORIES` في `app.js`.
2. ستظهر تلقائيًا في اختيار الخانات وشاشة اللعب.

---

## 🧪 استكشاف الأخطاء

- **لا تتم المزامنة بين الأجهزة**: تأكد أنك في وضع `supabase` (راجع console).
- **لا أرى اللاعبين الجدد**: تأكد أن كلا الجهازين يستخدم نفس `room code` وأنك نفّذت `supabase-schema.sql` بالكامل.
- **ظهر لي "بدأت اللعبة بالفعل"**: لا يمكن الدخول بعد بدء الجولة الأولى. ينتظر اللاعب حتى الجولة التالية (وسيُسمح له بالدخول في الجولة القادمة فقط إذا رجع الـ host للّوبي).
